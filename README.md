# 🎨 QR Code Generator

Zamonaviy va chiroyli QR kod yaratish veb-ilovasi. Next.js va Tailwind CSS asosida yaratilgan.

## ✨ Xususiyatlar

### 🎯 Ikki rejim:
- **Premium Mode** - Chiroyli gradient ramka + QR kod (100% skanerlanadi)
- **Simple Mode** - Oddiy qora-oq QR kod, hech qanday qo'shimchalarsiz

### 🎨 Premium rejimda:
- 8 xil tayyor gradient tema (Purple Dream, Ocean Wave, Sunset va boshqalar)
- Custom ranglar (boshlanish va tugash ranglari)
- Title va Subtitle qo'shish
- Logotip qo'shish (yuqori burchakda)
- Live preview - har o'zgarishda avtomatik yangilanadi

### ⚫ Simple rejimda:
- Faqat qora va oq rang
- Hech qanday fon yoki ramka yo'q
- Eng sodda va tez

### 📱 Umumiy xususiyatlar:
- QR kod o'lchamini sozlash (180px - 350px)
- Yuklab olish (PNG format)
- Tarixga saqlash (LocalStorage)
- Oxirgi QR kodlar ro'yxati
- Responsive dizayn (mobil va desktop)

## 🛠 Texnologiyalar

- **Framework:** Next.js 14 (App Router)
- **Til:** TypeScript
- **Stil:** Tailwind CSS
- **QR kod:** qrcode package
- **Ma'lumotlar bazasi:** LocalStorage (tarix uchun)
